Use the built in terminal in VsCode to interact with pcb boards
Ctrl+P -> ESP-IDF: Open ESP-IDF Terminal

If you're trying to include a header file that you're supposed to have
and VsCode isn't recognizning it, check the CMakeLists.txt file in the 
main folders and type in REQUIRES <header file name> to make VsCode
see it. Like the example explanation below \/

When setting up a project for Iot, make sure to add REQUIRES lwip
in the CMakeLists.txt in the main folder so you're able to include
internet header files in other files as well and not just exclusive
to main.c

To handle permission errors in linux
sudo usermod -aG dialout $USERNAME
newgrp dialout

idf.py build
idf.py flash - to run the example project (blinking LED)
idf.py fullclean - to clear cache

idf.py menucofig - to access the settings menu for the esp32
After making a change in teh settings menu, Press S to save, make
sure the sdkconfig file is confirmed that changes were made, Press Q
to quit the menu

idf.py openocd - to use the debugger (need the debugger board connected
				      to the esp32 board)
This command starts a local server that figures out which esp32 chip you're
using and tries to find a connection to the debugger board, and boots up the 
connection. 

To run the program use this command WITH OUTPUT ----> idf.py flash monitor

Make sure the Flash method to JTAG or it will result a serial error
which will fail to communicate with the debugger board
